# M3Ehtml 个人主页

一个基于纯 HTML/CSS/JavaScript 构建的类原生 Android **M3E (Material 3 Expressive)** 风格个人主页。

## ✨ 特性亮点

- **纯原生无依赖**：单文件 HTML，无需构建工具，直接打开即可运行。
- **M3E 原生体验**：
  - 启动时底部**充能水波纹**，卡片自下而上逐级浮现并亮起。
  - 点击头像，触发**粉色调扩散波纹**，扫过卡片、设置按钮时自动“充能”发光。
  - 头像 Q 弹模糊淡入效果。
  - 名字打字机效果（光标延迟消失），签名支持多文本循环打字与删除（可自定义间隔）。
  - 精确的点击水波纹反馈（区分卡片与内部标签）。
  - 全局禁用文本高亮（联系方式白名单可复制）。
- **高度集中的配置区**：所有文本、链接、图片、时间参数全部集中在 `SITE_CONFIG` 对象中，改内容不用翻代码。
- **主题切换**：支持浅色、深色、跟随系统三种模式，并自动保存到本地。
- **响应式设计**：完美适配 PC 和移动端设备。
